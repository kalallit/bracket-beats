# Logótipo do Spotify

As regras de marca do Spotify exigem o logótipo oficial junto a capas, músicas e playlists.
Descarrega-o em https://developer.spotify.com/design (secção de logótipos) e põe aqui:

- `logo-white.svg` (ou `.png`): logótipo completo branco, usado nos temas escuros
- `logo-black.svg` (ou `.png`): logótipo completo preto, usado nos temas claros

Não alteres as cores nem as proporções dos ficheiros.
